```markdown
## Fitur

- **Beranda:** Menampilkan halaman utama web
- **Koleksi:** Menampilkan daftar latihan olahraga
- **Pencarian dan Filter:** Mencari latihan berdasarkan judul dan kategori
- **Detail Latihan:** Melihat informasi lengkap latihan dan menghapus data
- **Tambah Latihan:** Menambahkan latihan olahraga baru
- **Statistik:** Menampilkan jumlah latihan berdasarkan kategori dan total latihan
- **Tentang:** Menampilkan identitas mahasiswa dan informasi aplikasi
- **Halaman 404:** Menampilkan halaman yang tidak ditemukan

## Menjalankan secara lokal

cd app
npm install
npm run dev

## Konsep React yang dipakai

- **Component:** Membagi tampilan menjadi beberapa komponen
- **useContext dan createContext:** Membagikan data koleksi ke beberapa halaman
- **Custom Hook:** Menggunakan useKoleksi untuk mengakses data koleksi
- **JSON:** Menggunakan file JSON untuk menyimpan data identitas
```
